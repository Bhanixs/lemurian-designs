# Lemurian Designers Website

## Goal

Create a polished, single-page website for Lemurian Designers using the supplied editorial references and the PDF’s business content.

## Build

- Create an immersive full-bleed stonework opening with minimal navigation and a strong serif statement.
- Use a warm mineral palette, dark forest accents, editorial typography, fine rules, and spacious asymmetrical layouts.
- Present the studio philosophy, selected work, core services, process, strengths, FAQs, and enquiry details in one flowing page.
- Use original generated stonework imagery tailored to masonry, sculpture, resort landscaping, and washbasins.
- Add working anchor navigation, mobile menu, expandable FAQs, and enquiry actions without inventing missing phone, address, or opening-hours details.
- Add complete page metadata and a custom brand favicon.

## Technical details

- Keep the existing TanStack Start structure and implement the page at `/`.
- Define colors, typography, spacing, and motion centrally in the existing design system.
- Use responsive layouts for mobile and desktop, with restrained entrance motion and reduced-motion support.
- Verify the finished page at desktop and mobile sizes, check interactions, and resolve preview errors.
